# UI polish

## Checklist
- Readable type hierarchy; enough contrast
- Spacing rhythm consistent (8px grid is fine)
- Primary action obvious on each screen
- Works at ~390px width without horizontal scroll
- Loading and empty states exist
- Destructive actions confirm or are clearly marked
- Prefer CSS transitions under 300ms; respect reduced-motion when easy

## Done when
A quick pass on phone-width and desktop looks intentional, not scaffolded.
